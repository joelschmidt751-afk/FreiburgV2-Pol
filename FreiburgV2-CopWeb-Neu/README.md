# FreiburgV2 Cop-Web – neue Website

## Starten
1. ZIP entpacken.
2. Öffne `index.html` mit einem aktuellen Browser oder lade den gesamten Ordner auf einen Webhost hoch.
3. Lass `style.css`, `app.js` und den Ordner `assets` neben `index.html` liegen.

## Wichtig
Dies ist eine eigenständige, responsive Frontend-Version mit Startseite, News, Informationen, Regeln, Team-Abteilungen und Login-/Registrierungsoberfläche.
**Login und Registrierung sind nur Demo-Interaktionen.** Sie speichern keine echten Konten und sind nicht mit ESX/MySQL verbunden. Für echte Benutzerkonten brauchst du ein Backend mit HTTPS, sicherem Passwort-Hashing, Sitzungen, CSRF-Schutz und serverseitiger Rollenprüfung.
Die Hintergrundgrafik ist in `assets/hero-freiburg.png` enthalten. Falls sie fehlt, entferne in `style.css` den Eintrag `url('assets/hero-freiburg.png')` aus `.hero`.
